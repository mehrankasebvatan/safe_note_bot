# 📝 Safe Note Bot

**A simple, free, and open-source notes and task manager built as a Telegram Mini App.**

Safe Note Bot helps you organize your notes, checklists, and daily tasks directly inside Telegram — without installing a separate application.

🔗 **[Open the Mini App](https://t.me/safe_note_bot/)**

## ✨ Features

- 📝 **Notes & Tags** — Create, organize, and categorize notes with tags.
- ✅ **Checklists** — Create checklists and track completed items.
- 📋 **Task Management** — Manage daily tasks with urgent, important, and normal priorities.
- 🔍 **Search** — Find notes by title, content, or tags.
- 📌 **Pinned Notes** — Keep important notes easily accessible.
- 🔒 **Password Lock** — Restrict access to the app with a numeric password.
- ☁️ **Cloud Storage** — Store notes and tasks using Telegram CloudStorage when supported.
- 🔄 **Data Synchronization** — Access cloud-stored data across devices using the same Telegram account and bot.
- 🌙 **Light & Dark Themes** — Choose your preferred appearance or follow system settings.
- 🌐 **Bilingual Interface** — Supports Persian (Farsi) and English.
- 📱 **Mobile-Friendly UI** — Designed for use inside Telegram on mobile devices.

## 🚀 Getting Started

1. Open [Safe Note Bot](https://t.me/safe_note_bot/).
2. Launch the Mini App through Telegram for the intended Telegram integration.
3. Create your first note, checklist, or task.
4. Organize your content with tags, priorities, and pinned notes.

## 💾 Storage

The app uses **Telegram CloudStorage** when the required Telegram Web App bridge and API are available.

When running outside a supported Telegram environment, it falls back to the browser's `localStorage` for testing.

Local browser storage is specific to that browser and device; it does not automatically synchronize with Telegram CloudStorage.

## 🔐 Security & Privacy

The optional password lock restricts access to the application. The password is stored as a salted hash when the Web Crypto API is available.

**Important:** The password lock does not encrypt note contents. It should not be considered a substitute for encrypted storage, and sensitive information should not be stored under the assumption that notes are encrypted.
